Continua o projeto "Kubo Launcher" (zip anexo). Lê primeiro README.md e PASSO_ATUAL.md.
É um launcher Minecraft original em Tauri 2 (Rust) + HTML/CSS/JS sem build, para Windows, Mac e Linux, leve e rápido a compilar. O tema é igual ao do meu client Kubo (variáveis CSS em src/index.html). Mantém o visual. O passo 2 foi escrito sem compilar: se algo não compilar, corrige primeiro.
Faz o PASSO 3: (a) descarregar o Java certo automaticamente por versão (javaVersion do json da Mojang); (b) suportar o loader Fabric (versões com inheritsFrom, meta.fabricmc.net); (c) injetar o mod Kubo na pasta mods de cada instalação, escolhendo o jar certo para a versão do jogo; (d) ler um manifesto remoto (URL configurável em Definições, um JSON que eu edito num site) com a versão mais recente do jar por versão do jogo, e atualizar sozinho ao jogar, com verificação SHA1.
